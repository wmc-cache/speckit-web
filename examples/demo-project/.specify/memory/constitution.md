# 团队协作平台 Constitution

## Core Principles

### I. 用户数据优先

所有功能都必须先回答“用户的数据存在哪里、谁能看到”。涉及个人信息的需求必须在规范中写明保留期限与可见范围。

### II. 测试先行（不可协商）

任何影响业务逻辑的改动都先写失败的测试，再写实现。

### III. 简单优先

能用一个服务完成的不拆成两个；新增依赖需要在方案中说明理由。

## 质量门禁

- 合并请求必须通过全部自动化检查。
- 用户可见文案必须同时提供中文与英文。

## Governance

本准则高于其它约定。修改准则需要在合并请求中说明原因并更新版本号。
